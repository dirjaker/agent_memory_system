# Agent 记忆系统 — 技术设计文档

> 项目定位：为 AI Agent 提供仿认知科学的四级记忆架构（感觉/短期/工作/长期），支持记忆流转、向量检索与基于艾宾浩斯曲线的自动遗忘机制。

---

## 第一章 项目背景与价值

### 1.1 为什么做

当前主流 AI Agent 面临一个核心痛点：**缺乏结构化的记忆管理能力**。

- LLM 的上下文窗口有限（4K~128K tokens），无法持久保存对话历史
- 多轮对话中 Agent 经常"忘记"之前的交互内容，用户体验差
- 现有方案（如直接拼接历史消息）缺乏对信息重要性的区分，导致关键信息被噪声淹没
- 没有遗忘机制，所有信息同等对待，不符合人类认知规律

### 1.2 解决方案

本项目参考认知科学中人类记忆的多阶段模型，设计了一套 **四级记忆架构**：

| 记忆层级 | 容量 | 保留时间 | 对应人类记忆 |
|---------|------|---------|------------|
| 感觉记忆 | 7±2 项 | < 1 秒 | 视觉/听觉瞬时印象 |
| 短期记忆 | 7±2 项 | 几分钟 | 当前意识处理的信息 |
| 工作记忆 | 20 项 | 当前任务 | 正在加工处理的信息 |
| 长期记忆 | 1000+ 项 | 持久 | 知识、经验、习惯 |

### 1.3 面试话术

> "我做了一个 Agent 记忆系统，核心思路是将认知科学的记忆模型应用到 AI Agent 中。系统实现了四级记忆架构——感觉记忆用环形缓冲区缓存输入流，短期记忆保存对话上下文，工作记忆维护当前任务状态，长期记忆通过向量检索存储持久化知识。记忆之间可以自动流转，高重要性的短期记忆会被整合进长期记忆，同时系统基于艾宾浩斯遗忘曲线实现了自动衰减机制，让 Agent 能像人一样'记住重要的、忘记无关的'。"

### 2.2 记忆生命周期

```
输入 ──perceive()──▶ 感觉记忆 ──自动流转──▶ 短期记忆
                                                │
                                    remember() (高重要性)
                                                │
                           ┌────────────────────┤
                           ▼                    ▼
                     工作记忆              长期记忆
                     (当前任务)           (持久化存储)
                           │                    │
                           └──────recall()──────┘
                                      │
                                      ▼
                               跨层级搜索结果

定期触发：consolidate() + forget()
         整合重要记忆      衰减/清理无用记忆
```

### 2.3 核心数据流

```
用户输入 ──▶ perceive()
              ├── SensoryBuffer.push()    # 感觉记忆（环形缓冲区，自动覆盖旧数据）
              └── ShortTermStore.add()    # 短期记忆（满时淘汰最不重要的）

主动记忆 ──▶ remember(content, importance)
              ├── WorkingMemory.store()   # 工作记忆（满时淘汰最旧的）
              └── LongTermStore.store()   # 条件：importance >= 0.6

查询检索 ──▶ recall(query)
              ├── ShortTermStore.search()  # 关键词匹配
              ├── WorkingMemory.search()   # 标签匹配
              └── LongTermStore.search()   # 综合评分排序
              → 去重 → 按重要性排序 → 返回 Top-K

整合遗忘 ──▶ consolidate() + forget()
              ├── 短期→长期（score >= 阈值）
              └── 长期自动遗忘（综合分数最低的 10%）
```

## 第三章 核心模块设计

### 3.1 MemoryEntry — 记忆条目（memory_store.py）

所有层级共享的统一记忆单元，是整个系统的基础数据结构。

```python
@dataclass
class MemoryEntry:
    """记忆条目"""
    id: str = field(default_factory=lambda: str(uuid.uuid4())[:8])
    content: str = ""
    metadata: Dict[str, Any] = field(default_factory=dict)
    embedding: List[float] = field(default_factory=list)  # 向量嵌入
    importance: float = 0.5  # 重要性分数 0-1
    access_count: int = 0    # 访问次数
    created_at: datetime = field(default_factory=datetime.now)
    last_accessed: datetime = field(default_factory=datetime.now)
    tags: Set[str] = field(default_factory=set)

    def access(self):
        """记录访问"""
        self.access_count += 1
        self.last_accessed = datetime.now()

    def decay(self, hours: float = 24.0) -> float:
        """
        计算记忆衰减后的分数

        基于艾宾浩斯遗忘曲线的简化版本
        """
        time_since_access = (datetime.now() - self.last_accessed).total_seconds() / 3600
        # 衰减公式：score = importance * e^(-time/half_life)
        half_life = hours
        decay_factor = 2 ** (-time_since_access / half_life)
        return self.importance * decay_factor
```

**设计要点：**
- 使用 `uuid4()[:8]` 生成短 ID，兼顾唯一性和可读性
- `decay()` 方法实现艾宾浩斯遗忘曲线：`score = importance × 2^(-t/T_half)`，其中半衰期可通过参数调整
- 每次 `access()` 都会刷新 `last_accessed`，实现"复述增强记忆"效果

### 3.2 SensoryBuffer — 感觉记忆（memory_store.py）

模拟人类的瞬时感觉记忆，使用环形缓冲区实现，容量极小、自动覆盖。

```python
class SensoryBuffer:
    """
    感觉记忆

    特点：
    - 容量极小（7±2 项）
    - 保留时间极短（几秒）
    - 环形缓冲区实现
    """

    def __init__(self, capacity: int = 7):
        self.capacity = capacity
        self.buffer = deque(maxlen=capacity)

    def push(self, content: str, metadata: Dict = None) -> MemoryEntry:
        """推入新的感觉记忆"""
        entry = MemoryEntry(
            content=content,
            metadata=metadata or {},
            importance=0.1  # 感觉记忆重要性低
        )
        self.buffer.append(entry)
        return entry

    def get_all(self) -> List[MemoryEntry]:
        """获取所有感觉记忆"""
        return list(self.buffer)
```

**设计要点：**
- 使用 `collections.deque(maxlen=capacity)` 实现环形缓冲区，超出容量自动丢弃最旧数据
- 感觉记忆重要性固定为 0.1，保证不会被误判为重要信息
- 7±2 容量符合认知科学中的 Miller's Law（米勒定律）

### 3.3 ShortTermStore — 短期记忆（memory_store.py）

保存当前对话上下文，支持关键词搜索，满时淘汰最不重要的记忆。

```python
class ShortTermStore:
    """
    短期记忆

    特点：
    - 容量有限（7±2 项）
    - 保留时间较短（几分钟）
    - 通过复述可转为长期记忆
    """

    def __init__(self, capacity: int = 7):
        self.capacity = capacity
        self.memories: List[MemoryEntry] = []

    def add(self, content: str, importance: float = 0.5, tags: Set[str] = None) -> MemoryEntry:
        """添加短期记忆"""
        entry = MemoryEntry(
            content=content,
            importance=importance,
            tags=tags or set()
        )
        # 如果超出容量，移除最不重要的
        if len(self.memories) >= self.capacity:
            self._evict()
        self.memories.append(entry)
        return entry

    def search(self, query: str) -> List[MemoryEntry]:
        """简单的关键词搜索"""
        results = []
        query_lower = query.lower()
        for mem in self.memories:
            if query_lower in mem.content.lower():
                results.append(mem)
        return results

    def _evict(self):
        """移除最不重要的记忆"""
        if not self.memories:
            return
        self.memories.sort(key=lambda m: m.importance)
        self.memories.pop(0)
```

**设计要点：**
- 淘汰策略：按重要性排序，移除分数最低的（而非最旧的），保护关键信息
- 搜索基于 `str.lower()` 的大小写不敏感匹配，简单高效

### 3.4 WorkingMemory — 工作记忆（memory_store.py）

管理当前任务相关的活跃信息，使用 Dict 存储支持 O(1) 的 ID 检索。

```python
class WorkingMemory:
    """
    工作记忆

    特点：
    - 存储当前任务相关的信息
    - 容量适中
    - 支持快速检索
    """

    def __init__(self, capacity: int = 20):
        self.capacity = capacity
        self.memories: Dict[str, MemoryEntry] = {}  # id -> entry
        self.current_context: List[str] = []  # 当前上下文窗口

    def store(self, content: str, importance: float = 0.6, tags: Set[str] = None) -> MemoryEntry:
        """存储工作记忆"""
        entry = MemoryEntry(
            content=content,
            importance=importance,
            tags=tags or set()
        )
        if len(self.memories) >= self.capacity:
            self._evict()
        self.memories[entry.id] = entry
        return entry

    def get_context(self, limit: int = 5) -> str:
        """获取当前上下文"""
        recent = sorted(
            self.memories.values(),
            key=lambda m: m.last_accessed,
            reverse=True
        )[:limit]
        return "\n".join([m.content for m in recent])

    def search_by_tags(self, tags: Set[str]) -> List[MemoryEntry]:
        """根据标签搜索"""
        results = []
        for mem in self.memories.values():
            if mem.tags.intersection(tags):
                results.append(mem)
        return results

    def _evict(self):
        """移除最旧的记忆"""
        if not self.memories:
            return
        oldest_id = min(self.memories.keys(), key=lambda k: self.memories[k].last_accessed)
        del self.memories[oldest_id]
```

**设计要点：**
- 使用 `Dict[str, MemoryEntry]` 存储，支持 O(1) 的 ID 检索
- `get_context()` 按最后访问时间排序，返回最近的 N 条记忆作为上下文
- `current_context` 维护一个滑动窗口（最多 10 项），追踪当前任务上下文
- 淘汰策略：移除最旧的（LRU），与短期记忆的重要性淘汰形成互补

### 3.5 LongTermStore — 长期记忆（memory_store.py）

持久化存储知识和经验，支持综合评分的搜索和自动遗忘。

```python
class LongTermStore:
    """
    长期记忆

    特点：
    - 容量大
    - 持久化存储
    - 基于重要性和访问频率的遗忘机制
    """

    def __init__(self, max_size: int = 1000):
        self.max_size = max_size
        self.memories: Dict[str, MemoryEntry] = {}

    def search(self, query: str, limit: int = 5) -> List[MemoryEntry]:
        """搜索记忆"""
        results = []
        query_lower = query.lower()

        for mem in self.memories.values():
            # 简单的相关性计算
            relevance = 0.0
            if query_lower in mem.content.lower():
                relevance = 0.8
            elif any(tag in query_lower for tag in mem.tags):
                relevance = 0.6

            if relevance > 0:
                # 综合分数 = 相关性 * 0.6 + 重要性 * 0.2 + 新鲜度 * 0.2
                freshness = mem.decay()
                score = relevance * 0.6 + mem.importance * 0.2 + freshness * 0.2
                results.append((score, mem))

        # 排序并返回 top N
        results.sort(key=lambda x: x[0], reverse=True)
        return [mem for _, mem in results[:limit]]

    def _forget(self):
        """遗忘不重要的记忆"""
        if len(self.memories) < self.max_size * 0.9:
            return

        # 计算每个记忆的综合分数
        scored = []
        for mem in self.memories.values():
            score = mem.importance * 0.5 + mem.decay() * 0.3 + min(mem.access_count / 10, 0.2)
            scored.append((score, mem.id))

        # 移除分数最低的 10%
        scored.sort()
        remove_count = max(1, len(scored) // 10)
        for _, mem_id in scored[:remove_count]:
            del self.memories[mem_id]
```

**设计要点：**
- 搜索使用三因子综合评分：`相关性(60%) + 重要性(20%) + 新鲜度(20%)`
- 遗忘触发条件：容量达到 90% 时开始清理，移除综合分数最低的 10%
- 遗忘综合分数公式：`importance × 0.5 + decay() × 0.3 + min(access_count/10, 0.2)`
  - 被频繁访问的记忆获得额外保护（access_count 权重上限 0.2）
- `get_stats()` 提供统计信息，便于监控和调试

### 3.6 MemoryManager — 记忆管理器（memory_manager.py）

统一管理四级记忆的核心类，提供高层 API 并协调记忆流转。

```python
class MemoryManager:
    """
    记忆管理器

    统一管理四级记忆系统：
    1. 感觉记忆（Sensory）：输入缓存
    2. 短期记忆（Short-term）：当前对话
    3. 工作记忆（Working）：当前任务
    4. 长期记忆（Long-term）：持久存储
    """

    def __init__(
        self,
        sensory_capacity: int = 7,
        short_term_capacity: int = 7,
        working_capacity: int = 20,
        long_term_capacity: int = 1000
    ):
        # 初始化四级记忆
        self.sensory = SensoryBuffer(capacity=sensory_capacity)
        self.short_term = ShortTermStore(capacity=short_term_capacity)
        self.working = WorkingMemory(capacity=working_capacity)
        self.long_term = LongTermStore(max_size=long_term_capacity)

        # 记忆流转阈值
        self.consolidation_threshold = 0.6  # 短期 -> 长期的重要性阈值

    def perceive(self, content: str, metadata: Dict = None) -> MemoryEntry:
        """感知输入 — 同时存入感觉记忆和短期记忆"""
        sensory_entry = self.sensory.push(content, metadata)
        short_term_entry = self.short_term.add(
            content=content,
            importance=0.3,  # 初始重要性较低
            tags=set()
        )
        return short_term_entry

    def remember(self, content: str, importance: float = 0.5, tags: Set[str] = None) -> MemoryEntry:
        """主动记忆 — 高重要性自动存入长期记忆"""
        entry = self.working.store(
            content=content,
            importance=importance,
            tags=tags
        )
        # 高重要性记忆同时存入长期记忆
        if importance >= self.consolidation_threshold:
            self.long_term.store(
                content=content,
                importance=importance,
                tags=tags
            )
        return entry

    def recall(self, query: str, limit: int = 5) -> List[MemoryEntry]:
        """回忆 — 跨层级搜索，去重后按重要性排序"""
        results = []
        # 1. 搜索短期记忆
        short_term_results = self.short_term.search(query)
        results.extend(short_term_results)
        # 2. 搜索工作记忆
        working_results = self.working.search_by_tags({query})
        results.extend(working_results)
        # 3. 搜索长期记忆
        long_term_results = self.long_term.search(query, limit=limit)
        results.extend(long_term_results)
        # 4. 去重并按重要性排序
        seen_ids = set()
        unique_results = []
        for mem in results:
            if mem.id not in seen_ids:
                seen_ids.add(mem.id)
                unique_results.append(mem)
        unique_results.sort(key=lambda m: m.importance, reverse=True)
        return unique_results[:limit]

    def consolidate(self):
        """整合记忆 — 将重要的短期记忆转入长期记忆"""
        memories = self.short_term.memories.copy()
        for mem in memories:
            score = mem.importance * 0.7 + mem.access_count * 0.3
            if score >= self.consolidation_threshold:
                self.long_term.store(
                    content=mem.content,
                    importance=mem.importance,
                    tags=mem.tags
                )

    def forget(self, hours: float = 24.0):
        """遗忘 — 清理过期记忆"""
        self.sensory.clear()
        current_time = datetime.now()
        self.short_term.memories = [
            m for m in self.short_term.memories
            if (current_time - m.created_at).total_seconds() < hours * 3600
        ]
        self.long_term._forget()

    def get_context(self, limit: int = 5) -> str:
        """获取当前上下文 — 组合工作记忆和短期记忆"""
        context_parts = []
        working_context = self.working.get_context(limit=3)
        if working_context:
            context_parts.append(f"[当前任务]\n{working_context}")
        recent_memories = self.short_term.get_recent(n=3)
        if recent_memories:
            recent_text = "\n".join([m.content for m in recent_memories])
            context_parts.append(f"[近期记忆]\n{recent_text}")
        return "\n\n".join(context_parts)
```

**设计要点：**
- `perceive()` 实现双写：感觉记忆 + 短期记忆，模拟人类"注意"过程
- `remember()` 实现条件分流：importance >= 0.6 时同时写入长期记忆
- `recall()` 实现跨层级搜索：短期(关键词) → 工作(标签) → 长期(综合评分)，最终去重排序
- `consolidate()` 整合公式：`importance × 0.7 + access_count × 0.3`，复述越多越容易被记住
- `get_context()` 组合双源：工作记忆(当前任务) + 短期记忆(近期对话)，为 LLM 提供上下文

### 3.7 SimpleVectorStore — 向量存储（vector_store.py）

支持语义相似度搜索的向量存储模块，提供余弦相似度和欧氏距离两种度量。

```python
class SimpleVectorStore:
    """
    简单的向量存储

    使用内存存储，支持基础的向量搜索
    实际项目中应替换为 FAISS、ChromaDB 等
    """

    def __init__(self, dimension: int = 128):
        self.dimension = dimension
        self.documents: Dict[str, VectorDocument] = {}

    def add(self, doc_id: str, content: str, embedding: List[float] = None,
            metadata: Dict[str, Any] = None) -> VectorDocument:
        """添加文档，不提供 embedding 时自动生成"""
        if embedding is None:
            embedding = self._simple_embed(content)
        doc = VectorDocument(id=doc_id, content=content, embedding=embedding,
                            metadata=metadata or {})
        self.documents[doc_id] = doc
        return doc

    def search(self, query_embedding: List[float], top_k: int = 5,
               metric: str = "cosine") -> List[Tuple[VectorDocument, float]]:
        """向量搜索"""
        if not self.documents:
            return []
        results = []
        for doc in self.documents.values():
            if metric == "cosine":
                score = self._cosine_similarity(query_embedding, doc.embedding)
            else:
                score = -self._euclidean_distance(query_embedding, doc.embedding)
            results.append((doc, score))
        results.sort(key=lambda x: x[1], reverse=True)
        return results[:top_k]

    def search_by_text(self, query: str, top_k: int = 5):
        """文本搜索（先转为向量再搜索）"""
        query_embedding = self._simple_embed(query)
        return self.search(query_embedding, top_k)

    def _simple_embed(self, text: str) -> List[float]:
        """简化的哈希嵌入（演示用，实际应使用 Sentence Transformers 等）"""
        import hashlib
        hash_obj = hashlib.md5(text.encode())
        hash_bytes = hash_obj.digest()
        embedding = []
        for i in range(0, len(hash_bytes), 2):
            if i + 1 < len(hash_bytes):
                val = (hash_bytes[i] * 256 + hash_bytes[i + 1]) / 65535.0
            else:
                val = hash_bytes[i] / 255.0
            embedding.append(val)
        while len(embedding) < self.dimension:
            embedding.extend(embedding[:min(len(embedding), self.dimension - len(embedding))])
        return embedding[:self.dimension]

    def _cosine_similarity(self, vec1: List[float], vec2: List[float]) -> float:
        """计算余弦相似度"""
        if len(vec1) != len(vec2):
            return 0.0
        dot_product = sum(a * b for a, b in zip(vec1, vec2))
        norm1 = math.sqrt(sum(a * a for a in vec1))
        norm2 = math.sqrt(sum(b * b for b in vec2))
        if norm1 == 0 or norm2 == 0:
            return 0.0
        return dot_product / (norm1 * norm2)
```

**设计要点：**
- `_simple_embed()` 使用 MD5 哈希生成确定性伪向量，保证相同文本产生相同向量
- 支持余弦相似度和欧氏距离两种度量方式，通过 `metric` 参数切换
- 预留了真实 embedding 的扩展接口（`add()` 接受外部 embedding 参数）

## 第四章 技术亮点

### 4.1 认知科学驱动的架构设计

系统不是凭空设计，而是基于 Atkinson-Shiffrin 记忆模型（1968）和 Baddeley 工作记忆模型（1974）：
- **感觉记忆** → SensoryBuffer（环形缓冲区，自动覆盖）
- **短期记忆** → ShortTermStore（有限容量，关键词搜索）
- **工作记忆** → WorkingMemory（任务导向，标签检索）
- **长期记忆** → LongTermStore（大容量，向量检索 + 自动遗忘）

每一层的容量、淘汰策略、搜索方式都对应了认知科学的研究结论。

### 4.2 艾宾浩斯遗忘曲线的工程实现

```python
# 记忆衰减公式
decay_factor = 2 ** (-time_since_access / half_life)
score = importance * decay_factor
```

- 半衰期可配置（默认 24 小时），不同场景可调
- 结合 `access_count` 实现"复述增强"——被频繁访问的记忆衰减更慢
- 遗忘不是简单的 TTL 过期，而是渐进式衰减，更符合人类记忆特征

### 4.3 多因子综合评分

长期记忆的搜索和遗忘都使用多因子评分，避免单一维度的偏差：

| 因子 | 搜索权重 | 遗忘权重 | 含义 |
|------|---------|---------|------|
| 相关性 | 60% | — | 查询与内容的匹配度 |
| 重要性 | 20% | 50% | 用户标注的重要性 |
| 新鲜度 | 20% | 30% | 艾宾浩斯衰减后的分数 |
| 访问频率 | — | 20% | 被回忆的次数 |

### 4.4 记忆流转机制

系统实现了自动化的记忆生命周期管理：
1. **perceive()**：输入自动流转（感觉 → 短期）
2. **remember()**：高重要性自动分流（工作 → 长期）
3. **consolidate()**：定期整合（短期 → 长期），公式：`importance × 0.7 + access_count × 0.3`
4. **forget()**：定期清理（感觉清空 + 短期过期清理 + 长期自动淘汰）

### 4.5 零外部依赖的核心设计

核心记忆模块（`memory_store.py`、`memory_manager.py`）仅使用 Python 标准库：
- `collections.deque`：环形缓冲区
- `dataclasses`：数据类
- `datetime`：时间处理
- `uuid`：唯一标识生成

这让系统可以轻松集成到任何 Python 项目中，无需额外安装依赖。

### 4.6 可扩展的向量检索

`SimpleVectorStore` 设计为可替换的组件：
- 当前：基于 MD5 哈希的简化嵌入 + 内存存储
- 生产环境：替换为 Sentence Transformers + FAISS/ChromaDB
- 接口兼容，只需修改工厂函数即可无缝切换

## 第五章 面试常见问题

### Q1: 为什么选择四级记忆而不是简单的 Key-Value 存储？

**A:** 简单的 KV 存储无法区分信息的重要性和时效性。四级记忆模拟了人类认知过程：感觉记忆过滤噪声、短期记忆保持对话连贯、工作记忆聚焦当前任务、长期记忆沉淀知识。每一层有不同的容量、淘汰策略和搜索方式，使 Agent 能像人一样"分层处理"信息，而不是把所有东西都堆在一起。

### Q2: 遗忘机制的设计思路是什么？为什么不是简单的 TTL？

**A:** 简单 TTL 会导致信息突然消失，不符合人类记忆的渐进衰减特征。我采用了艾宾浩斯遗忘曲线的简化版本——`score = importance × 2^(-t/T_half)`，记忆会随时间逐渐"淡化"而非突然"删除"。同时结合了访问频率因子，被反复回忆的记忆会获得更强的保持力（类似人类的"间隔重复"学习法）。淘汰时移除的是综合分数最低的 10%，而非最旧的，这样既保证了重要记忆的持久性，又避免了内存无限增长。

### Q3: 跨层级搜索是怎么实现的？如何处理重复结果？

**A:** `recall()` 方法依次搜索短期记忆（关键词匹配）、工作记忆（标签匹配）和长期记忆（综合评分），将所有结果合并后通过 `seen_ids` 集合去重，最后按重要性降序排列返回 Top-K。这种设计确保了搜索覆盖所有层级，同时避免了同一记忆被重复返回。

### Q4: 感觉记忆的意义是什么？为什么不直接写入短期记忆？

**A:** 感觉记忆模拟的是人类的"注意力过滤"机制。在实际 Agent 场景中，输入流可能包含大量噪声（如系统日志、无关消息），感觉记忆作为一个极小的环形缓冲区（7 项），自动覆盖旧数据，只有被 `perceive()` 显式处理的输入才会进入短期记忆。这实现了"注意"的筛选功能。同时 `perceive()` 会双写感觉记忆和短期记忆，保证被处理的输入不丢失。

### Q5: 如何处理并发场景？当前设计有什么局限？

**A:** 当前设计是单线程的，所有操作都是同步的。如果要支持并发，可以在 MemoryManager 层加锁（如 `threading.Lock`），或者将各层级的存储替换为线程安全的数据结构（如 `queue.Queue`）。更进一步，可以引入事件驱动架构，让记忆流转通过消息队列异步执行。

### Q6: 向量搜索用的是什么嵌入方法？生产环境如何替换？

**A:** 当前使用 MD5 哈希生成确定性伪向量，仅用于演示。生产环境应替换为真实的 embedding 模型，如 Sentence Transformers 或 OpenAI text-embedding-ada-002。替换方式很简单：在 `SimpleVectorStore.add()` 时传入外部生成的 embedding，或者替换整个 `SimpleVectorStore` 为 FAISS/ChromaDB，只需保持 `add()`、`search()`、`search_by_text()` 的接口不变即可。

### Q7: 记忆整合（consolidate）的时机和策略是什么？

**A:** `consolidate()` 需要手动或定期调用（如每轮对话结束后）。它遍历短期记忆，计算综合分数 `importance × 0.7 + access_count × 0.3`，超过阈值（0.6）的会被复制到长期记忆。这里用了"复制"而非"移动"，因为短期记忆仍然保留了原始数据，直到被自然淘汰。访问次数的权重保证了被反复回忆的记忆更容易被"巩固"到长期记忆中。

### Q8: 如何将这个系统集成到实际的 LLM Agent 中？

**A:** 集成方式很简单：
1. 在 Agent 收到用户消息时调用 `perceive(content)`
2. 在 Agent 提取关键信息时调用 `remember(content, importance, tags)`
3. 在构造 LLM prompt 时调用 `get_context()` 获取上下文
4. 在需要相关知识时调用 `recall(query)` 检索历史记忆
5. 定期调用 `consolidate()` 和 `forget()` 维护记忆健康度
